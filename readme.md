\# My Personal Website



A small place on the internet for a bit about me, the things I'm learning, and the projects I'm working on.



The design takes inspiration from a notebook: a warm paper background, blue accents, a sticky note, and simple dividing lines between sections. It's built with plain HTML and CSS.



\## What's on the site



\- \*\*About me\*\* — a short introduction and my current interests.

\- \*\*Projects\*\* — what I'm building, with a link to the code on GitHub.

\- \*\*Notes\*\* — a few things I've picked up while learning to make websites.

\- \*\*Links\*\* — where to find me on GitHub and Stardance.



The layout adjusts to smaller screens, and the navigation links jump to each section. There's also a back-to-top link at the bottom.



\## Files



| File | What's inside |

| --- | --- |

| `h\_index.html` | All the page content: headings, sections, navigation, and profile links. |

| `hellyeah.css` | The colours, fonts, spacing, responsive layout, sticky note, and browser illustration. |

| `README.md` | This overview of the website and its files. |



The HTML file loads `hellyeah.css`, so both files need to stay in the same folder.



\## Open the website



Download the files and open `h\_index.html` in a browser. There are no dependencies to install or build commands to run.



For GitHub Pages, rename `h\_index.html` to `index.html` so it opens as the homepage. Keep the stylesheet named `hellyeah.css`.



\## Editing



The text and links are in the HTML file. The main colours are defined at the top of the CSS file, and the smaller-screen adjustments are near the bottom.



Save your changes and refresh the browser to see them.
